# marp-modern

この環境の `marp` コマンドには、テーマ `modern` と、記法を足す拡張が入っている。見た目は、ここにある class と記法の組み合わせで作る。記法が効くのはこの環境の `marp` コマンドなので、人に渡すときは変換した PDF か PPTX を渡す。

## 変換

```
marp <原稿.md> [--pdf | --pptx | --images png] [-o <出力先>]
```

- 形式を省くと HTML になる。`--images png -o <dir>/s.png` は、スライドごとに `<dir>/s.001.png` から連番の画像を出す。
- 拡張は、直すべき箇所を `[modern]` で始まる警告として出す (題が長い、線の名前が図にない)。警告が出なくなるまで原稿を直す。

## 原稿の形

```
---
marp: true
theme: modern
paginate: true
---

<!-- _class: <種類> [<種類>...] -->
# <題>

<中身>

---

<次のスライド>
```

- スライドは `---` で区切る。
- 最初の `#` が、左上の題になる。題は 1 行で、全角 19 文字まで (半角は 2 文字で 1 文字分)。
- 中身の見出しは `##` から `######`。

## スライドの種類

| 種類 | 見た目 | 中身の書き方 |
|---|---|---|
| (なし) | 題と中身 | 自由 |
| `title` | 表紙。中央揃え | `# <題>` と `### <名前や日付>` |
| `toc` | 目次。6 項目までは 1 列、7 項目からは 2 列 | `# <題>` と番号付きリスト (`1. <章の名前>`) |
| `section` | 章の扉 | `## <章の名前>` だけ |
| `align-center` | 中身を縦の中央に置く | 自由 |
| `no-header` | 題のないスライド | 自由 |
| `small-text` | 文字と行間が 0.72 倍 | 自由 |
| `black` | 黒い地 | 画像や動画 |
| `image` | 画像を大きく 1 つ | `![](<画像>)` |
| `content-image` | 文の下に画像 | 文と `![](<画像>)` |
| `content-image-right`、`content-image-left` | 文の右 (左) に画像。幅は半々 | 文と `![](<画像>)`。`content-30` から `content-80` を足すと、文の幅がその割合になる |
| `column-layout` | 2 列 | 列ごとに `<div class="column">` で囲む |
| `text-center`、`all-text-center`、`h1-text-center` から `h6-text-center` | 中央揃え | 自由 |

## 自動で入るもの

- 目次の番号。リストの上から順に振られる。
- 章の扉の番号。扉が出てきた順に 1 から振られる。
- フッター。章の扉の次のスライドから、次の扉の前まで、`<番号>. <章の名前>` が入る。表紙と扉には入らない。

目次の項目は、章の扉と同じ名前を、同じ順番で書く。

| 変えたいこと | 書き方 |
|---|---|
| 1 枚だけフッターを変える | `<!-- _footer: <文字> -->` |
| 1 枚だけフッターを消す | `<!-- _footer: "" -->` |
| 章の番号を指定する | `## <span class="toc-num"><番号>.</span><章の名前>`。以降の番号はそこから続く |

## 枠

```
::: <名前> [<修飾>...] [#<id>]
<中身>
:::
```

- 中身は Markdown。枠の中に枠を入れられる。開いた数だけ `:::` で閉じる。
- 1 つの枠は、1 枚のスライドの中で開いて閉じる。
- `#<id>` は、図の線でつなぐときの名前。英字で始め、英数字と `-`、`_` を使う。

| 名前 | 役割 | 修飾 |
|---|---|---|
| `card` | 説明をまとめる枠。中身は `#### <見出し>`、文、箇条書き | `accent` (青の枠、強調)、`warn` (赤の枠、問題)、`square` (角丸なし) |
| `box` | 図の要素。中身は短い言葉。2 行にするときは `<br>`、補足は `<span class="sub"><補足></span>` | 下の表の色、`square` (角丸なし) |
| `row` | 中の枠を横に並べる | `center` (中央に寄せる) |
| `col` | 中の枠を縦に並べる | |
| `grid2`、`grid3` | 中の枠を等幅の 2 列、3 列に並べる | |
| `arrow` | 矢印の文字 (`→`、`↓` など) を、隣の box の中心に揃えて置く | `blue` |
| `diagram` | 中の要素を線でつなぐ図 | 配置の名前 (`row center`、`col`、`grid2`、`grid3`) |

box の色は、役割で決める。1 つの図の中で、同じ役割には同じ色を使う。

| 修飾 | 役割 |
|---|---|
| (なし) | 入力、データ |
| `dark` | 処理、モデル |
| `light` | 中間の結果 |
| `blue-fill` | 最終的な出力、結論。1 つの図に 1 つ |
| `warn` | 問題、否定 |
| `muted` | 未定、対象外 |

## 図の線

```
::: diagram [<配置>]
<#id を付けた box。row、col、grid2、grid3 で並べる>

<線>
<線>
:::
```

線は、`diagram` の直下に、線だけの段落として書く。前後を空行で区切り、1 行に 1 本。

```
<出る id>[.<辺>] <種類> <入る id>[.<辺>] [{<指定>...}] [: <ラベル>]
```

| 部分 | 書けるもの |
|---|---|
| 辺 | `top`、`right`、`bottom`、`left`。省くと、2 つの要素の位置から選ばれる |
| 種類 | `->` (矢印)、`--` (矢じりなし)、`<->` (両方向) |
| 指定 | `blue`、`red` (問題や否定)、`dashed` (戻る線、補助の線)。空白で区切って並べる |

経路は、出る辺と入る辺の組み合わせで決まる。

| 辺の組み合わせ | 経路 |
|---|---|
| 向かい合う辺 (`right` と `left`、`bottom` と `top`) | 2 つの要素の範囲が重なっていれば直線。重なっていなければ、中間で 1 回折れる |
| 直交する辺 (`bottom` と `left` など) | L 字 |
| 同じ向きの辺 (`top` と `top` など) | 要素の外側を回るコの字。戻る線に使う |

- 枝分かれと合流は、`col` で縦に積んだ組を、`diagram row center` の中で横に並べて作る。同じ辺から出る線、同じ辺に入る線は、折れる位置が揃う。
- 線が要素やほかの線に重なるときは、出る辺と入る辺を選び直す。
- コの字の線は、図の上か下に場所を取る。題に近いときは、スライドに `align-center` を付ける。
- 同じ内容のラベルは、1 本の線にだけ付ける。
- 図の幅は 1160px に収める。幅は、box ごとの「1 行の全角の文字数 × 29 + 36」と、列の間の 100 を足した数。超えるときは、box の言葉を短くするか `<br>` で 2 行にする、または列を減らす。

## 色と変数

- 文中の語の色: `<span class="<色>"><語></span>`。色は `red`、`orange`、`yellow`、`green`、`turquoise`、`blue`、`purple`、`pink`。強調は `blue`、否定は `red`。
- CSS を書くときは、値を変数で指す。色は `var(--<色>)`、`var(--<色>-<段>)` (段は 50、100、300、500、600、700、900)、`var(--gray-<段>)`。文字は `var(--font-size-<title|large|medium|body|small|caption|note>)`。余白は `var(--space-<1|2|3|4|5|6|8|10|15|25|30>)` (数字の 4 倍の px)。
