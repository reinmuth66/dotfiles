研究発表や授業のスライドのための見た目です。明るい灰の地に、濃い灰の文字と、1 つの青で組み立てます。飾りは使わず、色と大きさは全て法則から導きます。

## 考え方

- 遠くから読めることを最優先にする。本文は `body` (36px) より小さくしない。
- 色は意味を伝えるために使う。飾りのために色を足さない。
- 値を直接書かない。色、大きさ、余白、角丸、線は、必ずトークンの名前で指す。
- 1 枚のスライドで使う有彩色は、`blue` と、多くてもあと 1 色にする。

## 色

### 法則

色は OKLCH (見た目の明るさ、鮮やかさ、色相で表す方法) で決める。

- 色相は 8 つ: `red`、`orange`、`yellow`、`green`、`turquoise`、`blue`、`purple`、`pink`。無彩色は `gray`。
- 各色相に 7 つの段がある: 50、100、300、500、600、700、900。番号が大きいほど暗い。
- 同じ番号の色は、色相が違っても見た目の明るさが同じ。`blue-600` と `red-600` は同じ明るさ。
- 番号なしの名前 (`blue`、`red` など) は 600 の段を指す。`blue-light` などは 100 の段を指す。

新しい色が要るときは、色を作らずに、既にある色相の別の段を使う。

### 段の使い分け

| 段 | 使い道 | `bg` の上の文字 |
|---|---|---|
| 50、100 | 地。100 は box や表の見出しの地 | 使えない |
| 300 | 枠、塗り | 使えない |
| 500 | 大きな図形の塗り | 使えない |
| 600 | 主役。文字、枠、塗り | 使える |
| 700、900 | 濃い文字、暗い塗り | 使える |

600 以上の段で塗った上には `white` の文字を置く。100 以下の段の上には `text` の文字を置く。300 と 500 の段の上に文字を置かない。

### 役割

- 地は `bg`。box と card の地は `white`。
- 本文と見出しは `text`。補足は `text-sub`。フッターとページ番号は `text-footer`。
- 枠線は `border`。
- 強調は `accent` (`blue`)。否定や問題は `danger` (`red`)。
- 文中の色文字は、強調したい語だけに使う。文全体に色を付けない。
- `yellow` は、文字にするとオリーブ色に見える。「黄」を色として伝えたいときは `yellow-300` を塗りに使うか、文字には `orange` を使う。

### 図の中の色

図の box は、色で役割を示す。

| 役割 | 地 | 枠 | 文字 |
|---|---|---|---|
| 入力、データ | `white` | `gray-900` | `text` |
| 処理、モデル | `gray-900` | `gray-900` | `white` |
| 中間の結果 | `blue-light` | `blue` | `text` |
| 最終的な出力、結論 | `blue` | `blue` | `white` |
| 問題、否定 | `red-light` | `red` | `text` |
| 未定、対象外 | `gray-100` | `gray-300` の破線 | `text` |

色だけで区別しない。役割の違いは、box の中の言葉でも分かるようにする。

## 文字

- 書体は `sans` (Noto Sans、和文は BIZ UDPGothic)。コードは `mono` (M PLUS 1 Code)。
- 大きさは 8 段。本文 36px を基準に、1 段ごとに 1.2 倍。

| スタイル | 大きさ | 使い道 |
|---|---|---|
| `title` | 62px | スライドの題 |
| `large` | 52px | 大見出し |
| `medium` | 43px | 中見出し |
| `body` | 36px | 本文、箇条書き、表 |
| `small` | 30px | コード、card の中 |
| `caption` | 25px | 引用 |
| `note` | 21px | 注記、出典 |
| `footer` | 14px | フッター、ページ番号 |

- 太さは 400 と 700 だけ。見出しと強調は 700、それ以外は 400。
- 行間は、題と大見出しが `line-height-tight`、中見出しと注記が `line-height-normal`、本文が `line-height-loose`。
- 題は 1 行に収める。収まらないときは、大きさを下げずに言葉を削る。
- 文字を詰めるために大きさを 1 段下げるのは `small` まで。それでも入らない量は、スライドを分ける。
- 斜体は欧文だけに使う。和文の強調は太字にする。
- 絵文字は使わない。

## 余白

余白は 4px の倍数。名前の数字は、4px の何倍かを表す (`space-4` は 16px)。

- スライドの左右は `space-15`、下は `space-10`。題の帯の高さは `space-30`。
- 表紙と章の扉の左右は `space-25`。
- 段落やリストの下は `space-2`。見出しの上下は `space-1`。
- box の内側は `space-4`、card の内側は `space-6`。並べた box の間は `space-3`、列の間は `space-4`。

## 角丸、線、影

- 角丸は 2 つだけ。文中のコードは `radius-sm`、それ以外の枠 (コード、box、card) は `radius-md`。
- box と card は、`square` を足すと角丸がなくなる (`radius-none`)。1 つの図や 1 枚のスライドの中では、角丸ありとなしを混ぜない。
- 線は 3 つ。表・コードの枠・card は `border-thin`、box と強調した card は `border-medium`、引用の左の線は `border-thick`。
- 影は `shadow-image` の 1 つだけで、画像を地から浮かせたいときにだけ使う。box や card に影を付けない。
- グラデーションは使わない。

## 配置

- スライドは 16:9。題は左上に置き、本文は左揃えにする。中央揃えは、表紙と、1 つの主張だけを見せるスライドに使う。
- 1 枚のスライドに 1 つの主張。箇条書きは 2 階層まで。
- 図は左から右、上から下に読めるように並べる。

## 部品

部品は `components/` にある。見た目は `components/bundle.css` の class が決め、React の部品 (`window.Modern`) はその class を付けた HTML を出す。class を直接書いても、同じ見た目になる。

| 部品 | class | 使い道 |
|---|---|---|
| `Toc` | `toc`、`toc-num` | 目次。番号付きの 2 列 |
| `Card` | `card` (`accent`、`warn`) | 説明をまとめる枠。見出し、文、箇条書きを入れる |
| `Box` | `box` (`dark`、`light`、`blue-fill`、`warn`、`muted`) | 図の中の 1 つの要素。短い言葉を入れる |
| `Row`、`Col`、`Grid` | `row`、`col`、`grid2`、`grid3` | 並べ方 |
| `Diagram` | `diagram` | 要素同士を線でつなぐ図 |

- 文を読ませたいときは `Card`、関係を見せたいときは `Box` と `Diagram` を使う。
- 使う前に、その部品の `components/<部品>/README.md` を読む。
- ここにない部品が要るときは、まずこれらの組み合わせで作れないかを考える。新しい見た目を、その場で作らない。

## アイコンと画像

- アイコンの決まった集まりは持たない。必要なときは、単色の SVG を `text`、`accent`、`danger` のどれかで塗る。
- ロゴはない。名前は文字で書く。
- 写真や図版は加工せずに置く。地との境が分かりにくいときだけ `shadow-image` を付ける。
