目次を、番号付きの 2 列で見せる部品。章の扉の番号 (`toc-num`) も、同じ見た目にする。

## 使う場面

- 発表の最初に、章の一覧を見せるとき。
- 章が 4 つから 10 個のとき。それより少なければ、目次を省く。

## 渡すもの

章の名前の並び。番号は書かない (自動で振られる)。

## 書き方

HTML では、番号付きリストに `toc` を付ける。

```html
<ol class="toc">
  <li>研究背景・目的</li>
  <li>関連研究</li>
</ol>
```

React では `Modern.Toc` に `items` を渡す。

```jsx
<Modern.Toc items={["研究背景・目的", "関連研究"]} />
```

marp では、スライドに `toc` の class を付けて、番号付きリストを書く。

```markdown
<!-- _class: toc -->

# 目次

1. 研究背景・目的
2. 関連研究
```

## 決まり

- 章の名前は 1 行に収める。長いときは言葉を削る。
- 番号の色は `accent`。ほかの色に変えない。
- 章の扉 (marp の `<!-- _class: section -->`) の番号と、目次の番号を一致させる。marp では、どちらも自動で振られる。
