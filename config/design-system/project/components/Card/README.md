説明をひとまとめにする枠。見出し、文、箇条書きを入れる。

## 使う場面

- 2 つか 3 つの項目を並べて比べるとき (`Grid` の中に置く)。
- 1 つの主張を、スライドの中央で強く見せるとき (`accent`)。

## 種類

| 種類 | 役割 | 見た目 |
|---|---|---|
| (なし) | 並列の項目 | 細い灰の枠 |
| `accent` | 強調したい項目、提案 | 青の枠 |
| `warn` | 問題、従来の方法の欠点 | 赤の枠 |

`square` を足すと、角丸がなくなる (`class="card accent square"`、React では `square`、marp では `::: card accent square`)。並べた card では、全部に付けるか、全部に付けないかに揃える。

## 渡すもの

中身。見出しは `h4`、文は段落、箇条書きはリスト。文字は `small` の大きさになる。

## 書き方

```html
<div class="card accent">
  <h4>提案手法</h4>
  <ul><li>メタデータの影響を先に取り除く</li></ul>
</div>
```

```jsx
<Modern.Card variant="accent">
  <h4>提案手法</h4>
  <ul><li>メタデータの影響を先に取り除く</li></ul>
</Modern.Card>
```

marp:

```markdown
::: card accent
#### 提案手法
- メタデータの影響を先に取り除く
:::
```

## 決まり

- 並べる card は 3 つまで。それより多いときは表にする。
- `accent` と `warn` は、並べた中で 1 つずつまで。全部に付けると強調にならない。
- card の中に card を入れない。
- 影を付けない。
